# 🐍 Snake Game

A simple Snake game built with **Python** and **Pygame**. This project recreates the classic arcade game where you control a snake, collect food, and try to grow as long as possible without running into yourself.

It was a fun project to practice working with game loops, object-oriented programming, keyboard input, and collision detection using Pygame.

## Features

* 🎮 Classic Snake gameplay
* 🍎 Randomly generated food
* 📈 Live score counter
* 🌐 Snake wraps around the edges of the screen
* 💥 Automatic reset when the snake collides with itself
* 🟦 Clean grid-based game board

## Built With

* Python 3
* Pygame

## Installation

### Clone the repository

```bash
git clone https://github.com/yourusername/snake-game.git
cd snake-game
```

### Install Pygame

```bash
pip install pygame
```

### Run the game

```bash
python main.py
```

## Controls

| Key | Action     |
| --- | ---------- |
| ↑   | Move Up    |
| ↓   | Move Down  |
| ←   | Move Left  |
| →   | Move Right |

## How to Play

* Use the arrow keys to control the snake.
* Eat the orange food to grow longer and increase your score.
* The snake wraps around the edges of the screen, so you won't lose by leaving the map.
* If the snake runs into its own body, the game resets and you can start again.
